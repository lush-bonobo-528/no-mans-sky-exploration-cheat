# No Man's Sky Exploration Toolkit — feature reference

No Man's Sky Exploration Toolkit uses a concise workspace for journey notes, equipment profiles, and resource records. The feature map follows the same order as the project navigation.

| Section | Description |
|---|---|
| Journey notes | Route stages, transport context, and the notes associated with each part of the journey. |
| Equipment profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Resource records | Inventory and resource categories organized alongside their related values and notes. |

The project page follows the same section structure.
